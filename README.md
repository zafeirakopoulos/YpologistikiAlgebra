# Υπολογιστική Άλγεβρα — Σημειώσεις Μαθήματος

Σημειώσεις για το μάθημα 439 "Υπολογιστική Άλγεβρα" (ΕΚΠΑ, Τμήμα Μαθηματικών).

- [`index.html`](index.html) — η ιστοσελίδα των σημειώσεων (στατικό, self-contained HTML· τα κελιά κώδικα Julia/OSCAR είναι προϋπολογισμένα, όχι διαδραστικά).
- [`Ypologistiki_Algebra.pdf`](Ypologistiki_Algebra.pdf) — η ίδια ύλη σε μορφή PDF.
- [`slides/`](slides/index.html) — διαφάνειες μαθήματος, μία διάλεξη ανά κεφάλαιο (12 εβδομάδες), με εκτελεσμένα κελιά κώδικα Julia/OSCAR.

Πηγή: [Quarto](https://quarto.org/) `.qmd` έγγραφα, εκτελεσμένα με [OSCAR](https://www.oscar-system.org/) (Julia).
