# Υπολογιστική Άλγεβρα (439)

Υλικό για το μάθημα 439 "Υπολογιστική Άλγεβρα" (ΕΚΠΑ, Τμήμα Μαθηματικών).

Αρχική σελίδα: [`index.html`](index.html)

## Σημειώσεις

Δύο εκδοχές του ίδιου υλικού:

- **Σημειώσεις Μαθήματος** — [`YpolAlgNotes.html`](YpolAlgNotes.html) · [`YpolAlgNotes.pdf`](YpolAlgNotes.pdf)
  Η ύλη του μαθήματος σε 7 κεφάλαια: απομόνωση πραγματικών ριζών, απαλοίφουσα,
  ιδεώδη και αλγεβρικά σύνολα, βάσεις Gröbner, απαλοιφή, επίλυση πολυωνυμικών συστημάτων.

- **Βιβλίο Μαθήματος** — [`YpolAlgBook.html`](YpolAlgBook.html) · [`YpolAlgBook.pdf`](YpolAlgBook.pdf)
  Εκτενέστερη εκδοχή (11 κεφάλαια): επιπλέον γρήγοροι αλγόριθμοι (αριθμητική modulo $n$,
  ΚΘΥ, half-GCD, παραγοντοποίηση, LLL), παρεμβολή, πολυπλοκότητα και κρυπτογραφία,
  θέματα εργασιών εξαμήνου, και παράρτημα με επιπλέον ασκήσεις.

## Διαφάνειες και εργαστήρια

- [`slides/`](slides/index.html) — μία διάλεξη ανά εβδομάδα (13 εβδομάδες).
- [`labs/`](labs/index.html) — ένα εργαστήριο ανά εβδομάδα (~75΄), με ξεχωριστά φύλλα λύσεων.

## Παραγωγή

Όλα τα έγγραφα παράγονται από [Quarto](https://quarto.org/) `.qmd`, με τα κελιά κώδικα
εκτελεσμένα σε [OSCAR](https://www.oscar-system.org/) (Julia). Τα σχήματα είναι TikZ
(`.tex` → PDF για την έξοδο PDF, → SVG για την HTML). Τα αρχεία HTML είναι αυτοτελή:
ο κώδικας είναι προϋπολογισμένος, όχι διαδραστικός.
